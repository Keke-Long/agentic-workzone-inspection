Overview of the proposed Agentic S-RAG workflow for work-zone inspection.** Given frozen scene facts and a time-ordered multi-view image sequence, a multimodal controller autonomously searches a query-independent MUTCD structure, selects a source-visible Typical Application, extracts inspectable atomic requirements, and calls audited scene-evidence tools. The structured index contains MUTCD Sections, Typical Applications, source-hash clauses, and explicit cross-reference edges; it contains no hidden benchmark requirement IDs or correct-page whitelist. Scene tools return accepted observations and deterministic geometry measurements. The controller emits `satisfied` or `deficient` only when evidence is sufficient; otherwise it records `not_assessed` without human handoff. In ordinary-RAG ablations, regulation access changes while the controller, visual inputs, scene tools, and output schema remain fixed.
